setattr(obj, 'x', 5)	设置属性，obj.x = 5
getattr(obj, 'x')	获取属性，value = obj.x
hasattr(obj, 'x')	检查是否存在该属性

1. 属性名必须是字符串：如果你写 setattr(obj, x, 5) 而没有给 x 加引号，Python 会去找变量 x 的值作为属性名。
2. 私有属性：虽然 setattr 可以设置以双下划线开头的属性，但它不会自动触发 Python 的名称修饰（Name Mangling）机制，这可能会导致一些意外行为，建议仅用于常规属性。

---

1. 单前导下划线：_variable（内部使用），不会被导入。
2. 单末尾下划线：variable_（规避冲突），内置关键字占用了。
3. 双前导下划线：__variable（名称修饰），触发了 Python 的 Name Mangling，会把类 User 里的 __id 重命名为 _User__id。
4. 双前后下划线：__method__（魔术方法），Python 的内置特殊方法，具有特定的语法功能。永远不要自定义这种格式的变量。
5. 单个独立下划线：_（临时/无关紧要）。
	占位符）：当你必须接收一个变量。
	交互解释器）：在 Python 终端里，_ 代表上一次执行输出的结果。

记忆：_name约定的私有，__name强制的私有。
